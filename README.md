# ArunaTravel

ARUNA Travel — Go Further. Feel More.

Premium editorial travel website for Real Case Build #01 competition.
Single-file site (`index.html`): 7 hash-routed pages (Home, Packages,
Package Detail, Destinations, Gallery, About, Contact), Smart Trip Finder,
working filters, FAQ accordions, lightbox gallery, and dynamic WhatsApp
booking (+62 831-9345-7494).

Open `index.html` directly or deploy the folder to Netlify / Vercel.
